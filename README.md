# Instagram-Clone

A full-stack Instagram clone application that replicates core features of Instagram.  
The project is built with React on the frontend and Spring Boot on the backend, focusing on clean UI, scalable backend APIs, and real-world functionality.

---

## 🚀 Features

- User authentication & authorization  
- Create and upload posts  
- Like and comment on posts  
- Follow / Unfollow users  
- Responsive UI  
- Secure backend APIs  

---

## 🛠 Tech Stack

### Frontend
- React.js  
- Redux Toolkit  
- Tailwind CSS  

### Backend
- Spring Boot  
- Spring Security  
- REST APIs  

### Database
- MySQL
